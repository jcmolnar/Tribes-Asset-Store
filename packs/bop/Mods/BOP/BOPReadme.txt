// To run a server

1.) Unzip all files to DRIVE:\Tribes
	-winzip will put the files into DRIVE:\Tribes\BOP

2.) Modify a Tribes shortcut to run 'Tribes.exe -mod BOP'.
	-To modify your shortcut - right click on the tribes icon, choose properties,
		and add -mod BOP after tribes.exe in the target 

// To run a dedicated server

Same as above, except run 'infinitespawn *tribes -mod BOP -dedicated'
