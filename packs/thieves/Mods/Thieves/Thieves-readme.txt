****INSTALLATION****

	Step 1:
		Run the .EXE that you d/led. It should install  folder named T^r to your
		C:\Dynamix\Tribes directory if you do not find it there find it and move 
		it there
	
	Step 2:
		
		Create or modify a shortcut to your TRIBES.EXE file, and add the following 
		to it:
		
			-mod T^r
		
			Example:
		
			c:\Dynamix\Tribes\tribes.exe -mod T^r

		For a dedicated server, place the following at the end of the above line:
		
			-dedicated
			
			Example:
			
			c:\Dynamix\Tribes\tribes.exe -mod T^r -dedicated
		
		There is a program included with Tribes to allow for crash recovery...  
		Tribes has a tendency to crash every so often and exit the program... 
		Even if -dedicated is specified.  This program is called InfiniteSpawn.exe.
		Please read the documentation on this program for its use.
		
	Step 3:
	
		Click on the icon and start your game.  If you have problems, please refer 
		to the troubleshooting section of this document.
