How do I Install STAR mod ?

All you will need to do to install STAR mod is extract the STAR mod zip file. You will need to
put the SCRIPTS.VOL into a directory off of your /Dynamix/Tribes directory called Shifter. You
will need to put the shifter.cs file in your /Dynamix/Tribes/config directory. After this you
will need to run Tribes or InfiniteSpawn to start the game... Use the following run lines.
C:\Dynamix\Tribes\InfiniteSpawn *tribes -mod STAR shifter +exec shifter_v1.cs exec serverConfig.cs
dedicated

There is also a STAR shifter.cs included in ther latest version that will need to be
configured. This file contains the settings that make many of the Shifter features work the way
they do, so don't forget this file!!! That should just about do it... You will need to
configure your serverConf.cs file appropriately as well...

I hope you get this mod up easily.
